CÓMO DECIDIMOS

No todo lo que vende mucho merece la pena.

No usamos una fórmula mágica. La nota MePillo resume algo mucho más simple: si el producto es útil, si resulta fácil de usar, si su precio tiene sentido y a quién se lo recomendaríamos.
