# MePillo — Plataforma de recomendaciones y productos de afiliación

**Una plataforma web que ayuda a los usuarios a descubrir productos útiles mediante recomendaciones seleccionadas, valoraciones y análisis detallados.**

[**Visitar página web**](https://mepillo-20af5.web.app) | [**Repositorio GitHub**](https://github.com/sergiii15/mepillo-site)

## Descripción del proyecto

MePillo es una plataforma web de recomendaciones de productos disponibles en Amazon, diseñada para ayudar a los usuarios a tomar mejores decisiones de compra.

La página reúne productos de diferentes categorías y ofrece valoraciones editoriales, características técnicas, ventajas, desventajas y recomendaciones relacionadas.

Desarrollé MePillo como un proyecto independiente que combina mis conocimientos de desarrollo web con un modelo de negocio digital basado en el marketing de afiliados.

## Funcionalidades principales

- **Catálogo de productos:** Productos organizados en categorías como tecnología, gaming, hogar, deporte y motor.
- **Buscador:** Permite encontrar productos y explorar recomendaciones.
- **Ranking de productos:** Sección Top MePillo con los productos mejor valorados.
- **Análisis detallados:** Fichas con información técnica, puntuaciones, ventajas y aspectos que conviene tener en cuenta.
- **Enlaces de afiliados de Amazon:** Acceso a productos de Amazon mediante enlaces que pueden generar comisiones por compras válidas.
- **Diseño responsive:** Interfaz adaptada a ordenadores, tabletas y dispositivos móviles.
- **Productos relacionados:** Recomendaciones adicionales dentro de las fichas.
- **Transparencia:** Avisos sobre la utilización de enlaces de afiliados.

## Tecnologías utilizadas

- **Desarrollo frontend:** Diseño de interfaces web e interacción con el usuario.
- **Firebase Hosting:** Publicación y alojamiento de la página web.
- **Git y GitHub:** Control de versiones y gestión del código fuente.
- **Marketing de afiliados:** Integración de un modelo de monetización basado en comisiones.

## Cómo funciona

1. El usuario accede a MePillo y explora los productos disponibles.
2. Consulta las valoraciones, características y recomendaciones.
3. Selecciona el producto que mejor se adapta a sus necesidades.
4. Puede acceder a Amazon mediante un enlace de afiliado para realizar la compra.
5. Si la compra cumple los requisitos del programa de afiliados, puede generar una comisión.
